Frequently Asked Questions — PSV Sizing, Relief Hydraulics & Pump NPSHa

Process Engineering Knowledge Base

How do you size a Pressure Safety Valve (PSV) per API 520 Part I?

Under API 520 Part I (10th Edition), PSV orifice sizing calculates the required effective discharge area (A_req) at the absolute relieving pressure P_1 = P_set × (1 + overpressure) + P_atm. For gas or vapor service, the solver checks whether downstream total backpressure P_2 ≤ P_cf (critical choked flow) or P_2 > P_cf (subcritical flow using F_2), applies discharge (K_d), backpressure (K_b), and rupture disc (K_c) factors, and selects the next larger standard API 526 orifice letter.

Why does API 520 Part II limit PSV inlet pressure loss to 3% of set pressure?

API 520 Part II §7.3 stipulates that the total non-recoverable frictional pressure loss from the protected vessel nozzle to the PSV inlet flange must not exceed 3% of the gauge set pressure when evaluated at the valve's rated capacity (W_rated). Excessive inlet pressure drop causes violent rapid opening and reseating cycles known as valve chatter, which rapidly damages seating surfaces and mechanical joints.

When should you select a balanced bellows or pilot-operated PRV instead of a conventional PSV?

A conventional spring-loaded PSV is suitable only when built-up backpressure does not exceed allowable overpressure (10% for non-fire contingencies, 21% for external fire) and superimposed backpressure is constant. When total backpressure sits between 10% and 50% of set pressure or flare header pressure fluctuates, a balanced-bellows PRV is required (applying API 520 Fig. 30 K_b or Fig. 32 K_w capacity derating). Above 50% backpressure or when operating pressure is within 5% of set pressure, a pilot-operated PRV is selected.

How is external pool fire relief load calculated under API 521?

Per API 521 §4.4.13, heat absorption for liquid-wetted vessels exposed to an open pool fire up to 7.62 m (25 ft) above grade is Q = 43,200 · F · A_ws^0.82 Watts when prompt firefighting and drainage exist, or Q = 70,900 · F · A_ws^0.82 Watts where drainage is inadequate. Here A_ws is the wetted internal surface area in m² and F is the fireproofing environmental credit factor. Dividing Q by the latent heat of vaporization (λ) gives the required vapor relief mass flow W.

How is two-phase flashing flow sized using the Leung Omega (ω) parameter?

Following API 520 Part I Annex C (DIERS Leung homogeneous equilibrium method), the dimensionless compressibility parameter ω = α_0 + (ρ_0 · C_p · T_0 · P_0) / (λ · ρ_v0)² combines inlet void fraction and subcooled/saturated thermal flashing propensity inside the nozzle. From ω, the critical pressure ratio η_c and two-phase mass flux G_tp (kg/m²·s) determine the required orifice area.

How do you calculate pump NPSHa and verify API 610 hydraulic compliance?

Available Net Positive Suction Head (NPSHa) at the pump suction nozzle is computed as NPSHa = (P_suction,abs − P_vapor,abs) × 10⁵ / (ρ · g) in meters of liquid head. Per API 610, NPSHa must exceed vendor NPSHr by at least max(1.0 m, 1.10 × NPSHr) to prevent cavitation, while downstream control valve differential pressure is checked against dynamic friction and liquid pressure recovery factor F_L per IEC 60534.
